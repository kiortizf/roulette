# Sound Effects

Add your sound files here:

- `spin.mp3` - Roulette wheel spinning sound
- `winner.mp3` - Celebration sound when winner is announced
- `click.mp3` - Button click feedback
- `vote.mp3` - Voting sound effect

## Free Sound Resources

- [Freesound.org](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
- [Mixkit](https://mixkit.co/free-sound-effects/)

## Example Files Needed

1. **spin.mp3**: Wheel spinning, ~2-3 seconds
2. **winner.mp3**: Fanfare/celebration, ~1-2 seconds
3. **click.mp3**: Short click/tap, ~0.1 seconds
4. **vote.mp3**: Upvote/downvote feedback, ~0.2 seconds

All files should be MP3 format, < 100KB each for fast loading.
